# RepoBuddy

An AI-powered assistant that helps developers understand repositories
and plan open-source contributions.

## Planned Features

- Repository overview and setup guidance
- AI-powered issue breakdown
- Contribution checklist
- Open-source project readiness checks

## Technology Stack

- React
- Vite
- TypeScript
- Node.js
- Express
- Ollama

## Status

Currently under development.
